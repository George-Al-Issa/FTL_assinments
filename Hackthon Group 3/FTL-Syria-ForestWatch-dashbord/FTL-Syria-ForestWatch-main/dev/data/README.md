# Group 3 supplied datasets

These files are the datasets supplied by the team and are now included in the dashboard build:

- `cru-x0.5_timeseries.xlsx` — CRU climate series (`pr`, `tas`, `tasmax`, `tasmin`)
- `FAOSTAT_data_land_use.csv` — FAOSTAT land-use indicators
- `FAOSTAT_data_land_cover.csv` — FAOSTAT land-cover indicators
- `FAOSTAT_data_forest_emissions.csv` — FAOSTAT forest emissions/removals
- `FAOSTAT_data_en_9-29-2026.csv` — FAOSTAT forestry production/trade

The dashboard builder now uses these local files first so the merged dashboard is reproducible without requiring API credentials.
